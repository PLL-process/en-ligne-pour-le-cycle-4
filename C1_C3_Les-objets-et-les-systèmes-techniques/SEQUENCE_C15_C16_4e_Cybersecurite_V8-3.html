🧠 2. Programme Python — Touche Tab & Indentation Score : 0/3

Rappel amélioré : En Python, l’indentation (décalage vers la droite) n’est pas décorative : c’est une règle obligatoire qui définit les blocs (if, for, def…).
La touche Tab insère souvent 4 espaces. Ne mélange pas Tab et espaces dans un même fichier.

💥 Erreur fréquente

age = 20
if age >= 18:
print("Tu es majeur.")  # <-- Indentation manquante (provoque une erreur)
print("Fin du programme.")

Sortie possible : IndentationError: expected an indented block

✅ Exécution OK

age = 20
if age >= 18:
    print("Tu es majeur.")
print("Fin du programme.")

🔒 HTTPS vs HTTP

# Vérifie si l’URL est sécurisée
url = "http://example.com"

if url.startswith("https://"):
    print("Connexion sécurisée ✅ (HTTPS)")
else:
    print("Connexion non sécurisée ⚠️ (HTTP)")
