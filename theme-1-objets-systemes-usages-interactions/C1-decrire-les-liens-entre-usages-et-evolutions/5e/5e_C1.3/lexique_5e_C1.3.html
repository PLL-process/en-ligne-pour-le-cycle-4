C1.3 · 16 notions

Un acteur du système
Un acteur agit sur l’information ou s’en sert.
Une action et une trace
Compétence exacte + niveau + repère + action + trace.
Une colonne qui fait décider
Traiter les données consiste notamment à calculer, classer ou qualifier.
Une donnée brute
Donnée = valeur ; information = donnée interprétée dans un contexte.
Donnée ou information
Une information est une donnée interprétée pour répondre à un besoin.
Une donnée simulée
Une ressource fiable distingue faits, simulations et hypothèses.
L'ordre des étapes
Le traitement transforme des données en information utile.
Protéger les personnes dans un tableau
Minimiser les données : ne conserver que ce qui est nécessaire.
Une règle à deux conditions
Avec OU, une seule condition vraie suffit.
Les règles du système
Les procédures et les droits font partie du système d’information.
Le rôle d'un système d'information
Système d’information = acteurs + règles + données + matériels + logiciels + réseaux.
Le rôle d'une base de données
Une base permet d’enregistrer, rechercher et mettre à jour des données.
Le rôle du réseau
Réseau = transmettre ; serveur = traiter ; base = stocker.
La trace d’un traitement réussi
La trace doit rendre visibles les opérations réalisées.
Transférer sans copier
Transférer une solution, c’est conserver, modifier ou abandonner certains choix.
Trier et filtrer : quelle compétence ?
Le tableur n’est qu’un outil ; la compétence est le traitement réalisé.

C1.4 · 14 notions

Une arborescence claire
Une arborescence doit permettre à une autre personne de retrouver les fichiers.
Ce qu'on archive
Une version remplacée va dans l'archive : gardée, mais à part de la version en cours.
Deux fichiers, un même nom
Versionner, c’est identifier l’évolution d’un document.
La double sauvegarde
Sauvegarder ne signifie pas diffuser à tout le monde.
L'extension d'un fichier
L’extension se trouve après le dernier point du nom.
Filtrer
Un filtre ne détruit pas les données.
Lire un chemin
Chaque dossier doit correspondre à une étape du travail.
Un nom de fichier réutilisable
Nommer un fichier pour qu’une autre personne le comprenne sans l’ouvrir.
Ranger et sauvegarder : quelle compétence ?
La compétence doit correspondre à l’action observable et à la trace.
Le sens d'un tri décroissant
Décroissant : du plus grand au plus petit, sur la colonne choisie.
Le séparateur d'un CSV
À l'import d'un CSV, on choisit le signe qui sépare les valeurs dans le fichier : ici, le point-virgule.
La trace d’un rangement réussi
Une preuve CRCN doit pouvoir être observée après l’activité.
Travailler sur une copie
Les données brutes sont une référence à conserver intacte.
Trier
Trier = ordonner ; filtrer = afficher seulement certaines lignes.
