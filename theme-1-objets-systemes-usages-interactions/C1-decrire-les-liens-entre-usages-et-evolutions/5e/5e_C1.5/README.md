## Ciblage 5e

Pour les élèves de 5e, privilégier les activités portant sur :

1. la création et la protection d’un mot de passe robuste ;
2. la reconnaissance d’un message ou d’un lien suspect ;
3. la protection des données personnelles et de l’identité numérique ;
4. le respect de la propriété intellectuelle et des licences.

Les approfondissements réservés aux élèves plus avancés restent facultatifs.
