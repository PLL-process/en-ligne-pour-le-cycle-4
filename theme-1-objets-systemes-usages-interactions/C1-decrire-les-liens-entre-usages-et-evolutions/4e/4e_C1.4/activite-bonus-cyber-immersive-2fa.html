🔍 Qu’est-ce qu’une URL ? C’est l’adresse d’une ressource sur Internet (ex. https://www.education.gouv.fr).
🔒 HTTPS = chiffré et sécurisé. ⚠️ HTTP = non chiffré, donc vulnérable.

🧠 Synthèse : Touche Tab & Indentation en Python

En Python, l’indentation (décalage vers la droite) est obligatoire pour délimiter les blocs (if, for, def...). La touche Tab insère souvent 4 espaces.

📍 Sur un clavier standard, la touche Tab se situe au-dessus de Caps Lock et à gauche de la touche A (AZERTY).

# Vérifie si l’URL est sécurisée
url = "http://example.com"  # modifiez cette variable pour tester

if url.startswith("https://"):
    print("Connexion sécurisée ✅ (HTTPS)")
else:
    print("Connexion non sécurisée ⚠️ (HTTP)")

⚠️ Erreur fréquente : IndentationError

Python attend une indentation après if/for/etc. Sans cela → IndentationError.

🔐 Comprendre le 2FA (Authentification à deux facteurs)

Le 2FA demande deux preuves d’identité pour se connecter : c’est une couche de sécurité supplémentaire.

  • 📱 Code reçu par SMS
  • 🔐 Application d’authentification (Google/Microsoft Authenticator)
  • 🔔 Notification “push” sur ton téléphone
  • 🔑 Clé de sécurité physique (YubiKey…)

ℹ️ Rappel – Définitions (extrait du 1.a)

  • Ransomware : chiffre vos fichiers et demande une rançon.
  • Phishing : se fait passer pour un service afin de voler des informations.
  • MITM : intercepte les communications sur un réseau.
  • DDoS : submerge un service de requêtes jusqu’à l’indisponibilité.
