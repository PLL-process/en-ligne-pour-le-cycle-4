## Note sur les codes

Les anciens noms de fichiers (« C15_C16 ») renvoyaient aux codes **5e** du référentiel Nathan
(5e_C1.5 cybersécurité, 5e_C1.6 cyberviolence) — en 4e, le C1 s'arrête à C1.4. La séquence étant
écrite pour des classes de 4e, elle est rangée ici (4e_C1.4 : identité numérique, témoins de
connexion, usage raisonné) et couvre aussi, en croisement, 5e_C1.5 et 5e_C1.6.

Versions V4 → V15 : conservées dans `_archive-anciennes-versions/`.
