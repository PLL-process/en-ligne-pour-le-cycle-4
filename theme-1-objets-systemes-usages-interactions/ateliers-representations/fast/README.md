# Atelier « Des fonctions aux solutions techniques » — Des fonctions aux solutions techniques : le diagramme FAST (Function Analysis System Technique, « technique d'analyse fonctionnelle »)

Le schéma qui les relie s'appelle couramment le diagramme FAST, de l'anglais Function Analysis System Technique (« technique d'analyse fonctionnelle »). Il fait le lien entre le « pourquoi » (à quoi sert l'objet) et le « comment » (ce qui, dans l'objet, le fait).
