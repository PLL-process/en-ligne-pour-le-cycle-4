# 5e_C8.3 — Vérifier en suivant un protocole (couvert par une séquence mutualisée)

> Vérifier le comportement et les performances d'un objet technique en suivant un
> protocole fourni.

Le verbe de la 5ᵉ est **suivre**, pas proposer : le protocole est donné, l'élève
l'applique et relève. Ce code est travaillé dans le **mini-projet d'objet de 5ᵉ** :

[`5e_C8.1`](../5e_C8.1/README.md), qui pointe vers la même séquence : en 5ᵉ, valider
n'est pas une séance à part, c'est le dernier geste du mini-projet — on a fabriqué,
on éprouve.
