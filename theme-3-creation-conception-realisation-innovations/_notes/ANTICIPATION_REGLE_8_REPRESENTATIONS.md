# Anticipation — Règle d'or n°8
## Représentations technologiques utiles, progressives et traçables

*Note de production Thème 3 — en attente du texte officiel Pascal.  
Préparation pour le Conseil des IA (25/07/2026).*

### Ce que la discipline exige (constat partagé)
Les chaînes d'énergie et d'information, les schémas-blocs, les algorithmes et les protocoles ne sont pas des illustrations : ce sont **des outils de pensée**. Un élève de cycle 4 doit **produire**, **lire** et **faire évoluer** ces représentations — pas seulement les contempler.

### Trois exigences anticipées (à aligner sur le texte final)

1. **Utiles**  
   Chaque représentation sert une décision ou une production : choisir un matériau, valider un test, corriger un programme, argumenter une solution. Si l'élève peut répondre sans la lire / sans la tracer, elle est superflue (même logique que images v2).

2. **Progressives**  
   - 5e : schémas simples, blocs nommés, flèches sens unique, peu de symboles.  
   - 4e : chaînes structurées (info haut / énergie bas — règle 6), critères de test, premiers tableaux de validation.  
   - 3e : schémas complets, justifications croisées, algorithmes / programmes avec mise au point, représentations destinées à convaincre (DNB).

3. **Traçables**  
   Toute représentation demandée produit une **trace** : croquis daté, schéma numérisé, tableau de tests, pseudo-code, version v1 → v2. Pas de « on a vu le schéma au tableau » sans production élève.

### Lien avec les règles déjà en vigueur

### Application Thème 3 (création / conception / validation / programme)
- **C7** : croquis de solutions, tableau multicritère matériaux → traces de conception.  
- **C8** : protocole + tableau de résultats → représentation du **raisonnement de validation**.  
- **C9** : pseudo-code + tableau de scénarios → représentation de l'algorithme et de sa mise au point.

### Action immédiate (avant texte final)
Dans chaque nouvelle séquence Thème 3 :
- au moins **une production graphique ou tabulaire** exigée de l'élève ;
- niveau de complexité calibré (5e / 4e / 3e) ;
- consigne qui force la **lecture** ou le **tracé**, pas la décoration ;
- si chaînes d'énergie/information : règle 6 + encadré canonique.
