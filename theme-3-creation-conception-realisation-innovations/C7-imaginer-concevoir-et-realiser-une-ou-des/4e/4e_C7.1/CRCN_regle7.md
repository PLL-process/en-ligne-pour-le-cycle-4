## Compétences retenues (judicieuses pour C7)

### CRCN 3.1 — Développer des documents textuels · Niveau 2
- **Repère** : Utiliser les fonctions simples d'une application pour produire des contenus majoritairement textuels associés à une structure (liste, tableau).
- **Action observable** : L'élève complète un planning de conception (tâches + durées) et rédige le choix d'une solution avec justification.
- **Trace** : Planning renseigné dans la séquence (ou copie cahier) + paragraphe de choix solution A/B.

### CRCN 1.2 — Gérer des données · Niveau 1–2
- **Repère** : Sauvegarder des fichiers dans l'ordinateur utilisé et les retrouver · organiser des données pour les réutiliser.
- **Action observable** : L'élève enregistre identité + hypothèse via localStorage (ou export personnel) et les retrouve en rouvrant la page.
- **Trace** : Clés `techno_4e_C7_identite` / `techno_4e_C7_hypothese` présentes ; démonstration de reprise en début de séance 2.
