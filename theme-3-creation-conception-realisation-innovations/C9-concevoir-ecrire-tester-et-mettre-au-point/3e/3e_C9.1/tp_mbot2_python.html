🧩 20 questions à trous — Boucles

1 pt chacune • Essais dégressifs (3→2→1)

📘 Consignes

  • 💬 Lis bien la consigne avant d’écrire ton code.
  • 🧩 Tape exactement la ligne de code Python demandée.
  • ⚠️ Respecte les minuscules et majuscules (comme un mot de passe).
  • 🔠 Sois attentif aux espaces et à la ponctuation (par ex. :, " ").
  • ⏳ Tu as 3 essais : le score baisse à chaque erreur.
  • 💡 Si tu es bloqué, clique sur « Aide » pour un indice partiel.
  • ✅ La correction complète s’affiche après les 3 essais.

💻 Exemple en Python de correction :

# Boucle simple : répète 3 fois (Ceci est un commentaire avec le symbole # en début de ligne)
for i in range(3):
    print("Bonjour !")  # ce bloc est indenté de 4 espaces

🔍 Ce code affiche trois fois le mot Bonjour !. Chaque ligne commence avec la même indentation (le même retrait à gauche).
L'indentation est nécessaire chaque fois que tu ouvres un bloc de code, par exemple après :

  • if, elif, else (conditions)
  • for, while (boucles)
  • def, class (fonctions ou classes)
  • try, except, finally (gestion d'erreurs)
  • Toute structure où la ligne se termine par :

Exemple :

 python
 
 if x > 0:
     print("x est positif")  # ce bloc est indenté (4 espaces)
📌 Sans cette indentation, Python renverra une erreur de syntaxe.
