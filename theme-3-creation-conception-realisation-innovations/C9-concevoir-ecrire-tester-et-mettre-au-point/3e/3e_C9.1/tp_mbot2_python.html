📘 Consignes

  • 💬 Lis bien la consigne avant d’écrire ton code.
  • 🧩 Tape exactement la ligne de code Python demandée.
  • ⚠️ Respecte les minuscules et majuscules (comme un mot de passe).
  • 🔠 Sois attentif aux espaces et à la ponctuation (par ex. :, " ").
  • ⏳ Tu as 3 essais : le score baisse à chaque erreur.
  • 💡 Si tu es bloqué, clique sur « Aide » pour un indice partiel.
  • ✅ La correction complète s’affiche après les 3 essais.

💻 Exemple en Python de correction :

# Boucle simple : répète 3 fois (Ceci est un commentaire avec le symbole # en début de ligne)
for i in range(3):
    print("Bonjour !")  # ce bloc est indenté de 4 espaces

🔍 Ce code affiche trois fois le mot Bonjour !. Chaque ligne commence avec la même indentation (le même retrait à gauche).
L'indentation est nécessaire chaque fois que tu ouvres un bloc de code, par exemple après :

  • if, elif, else (conditions)
  • for, while (boucles)
  • def, class (fonctions ou classes)
  • try, except, finally (gestion d'erreurs)
  • Toute structure où la ligne se termine par :

Exemple :

 python
 
 if x > 0:
     print("x est positif")  # ce bloc est indenté (4 espaces)
📌 Sans cette indentation, Python renverra une erreur de syntaxe.

📖 Corrigé du Bonus (à ouvrir APRÈS ton essai)

1. La variable qui ment.

Exemple : on met la vitesse entre guillemets, puis on calcule avec.

vitesse = "40"
vitesse = vitesse + 10

Python s'arrête et affiche une erreur de type : TypeError.
Le message exact change selon la ligne et selon l'appareil, mais ce mot y est presque toujours.

En français, pour quelqu'un qui ne programme pas :
« Tu me donnes un texte là où j'attends un nombre : je ne sais pas calculer avec un texte. »

Pourquoi : "40", entre guillemets, est un texte ; 40 est un nombre.
Ils se ressemblent à l'écran ; pour Python, ce sont deux types différents.

2. Le robot sans robot.

Exemple : la fonction n'envoie plus rien aux moteurs ; elle écrit ce qu'elle aurait commandé.

def avancer(vitesse, duree):
    print("AVANCER à", vitesse, "% pendant", duree, "s")

avancer(40, 1)

À quoi sert un programme qui ne pilote rien :
· à vérifier l'ordre des actions et les valeurs sans robot : à la maison, ou quand il n'y a qu'un robot pour quatre ;
· à trouver les erreurs avant de risquer le matériel ;
· à garder une trace écrite de ce que le robot fera.

C'est une simulation : elle prouve la logique, pas le mouvement réel (les roues peuvent patiner).

3. Le nom qui explique.

Exemples :
· v devient vitesse_pourcent ;
· d devient distance_cm ;
· t devient duree_s.

Les commentaires que tu peux supprimer : tous ceux qui disaient seulement ce que contient une variable (« v est la vitesse »).
Le nom le dit maintenant, avec son unité.

Ceux que tu gardes : ceux qui disent pourquoi (« 15 cm : la distance de sécurité devant un mur »).
