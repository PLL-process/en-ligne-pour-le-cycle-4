MAP · 7 notions

Le banc de tests
Un test par cas + un test par frontière. Les bugs vivent aux frontières.
Le cas limite
> ou >= : c'est le CAHIER DES CHARGES qui tranche, et un test frontière qui vérifie.
Du programme au système
Dans un système réel, la variable devient commande : l'information pilote l'énergie (règle n°6 !).
Élaborer avant de taper
Élaborer (français) → traduire (Python) → tester. Le plan d'abord.
Fini, vraiment fini ?
Au point = tous les tests verts. Le banc reste, prêt pour la prochaine modification.
La non-régression
Toute correction → rejouer TOUS les tests. C'est la non-régression.
Pourquoi une fonction
Fonction = machine réutilisable et testable : reçoit des paramètres, renvoie un résultat.

PRG · 7 notions

= ou == ?
= range, == demande. Le if n'accepte que des questions.
Une chose à la fois
Une correction → une réexécution. Toujours.
Le message d'erreur, un allié
Lire le message d'erreur EN ENTIER : il donne l'opération et les types coupables.
L'ordre des lignes
Une variable se crée AVANT de s'utiliser : l'ordre des lignes est un choix de conception.
Prédire avant d'exécuter
Prédire → tester → reporter : l'écart prédiction/réalité est le meilleur professeur.
Relire un programme d'un coup d'œil
init à 0 + « c = c + 1 » = compteur. Apprendre à reconnaître les MOTIFS.
La trace du technicien
Bug silencieux → print() aux étapes clés : rendre visible, puis raisonner.

TYP · 8 notions

L'affichage mixte
Dans print, la virgule sépare et évalue ; le + colle (et exige le même type).
Le décodeur
int() et float() convertissent le texte en nombre.
Le doute méthodique
En cas de doute : type(x). Mesurer plutôt que supposer.
L'opération impossible
str − int → TypeError. L'erreur de type est une ALLIÉE : elle montre le bug.
Le piège des guillemets
str + str = collage. Le type décide du métier du +.
Les quatre familles
int entier · float à virgule-point · str entre guillemets · bool True/False.
La virgule qui fâche
Décimale = point. La virgule sépare, elle ne « décimale » pas.
Vrai ou faux
Comparer produit un bool : le carburant des if.

VAR · 8 notions

La boîte étiquetée
Variable = étiquette + contenu, dans la mémoire.
Le compteur
total = total + x : le motif « compteur », à reconnaître au premier regard.
L'échange de contenus
Échanger deux variables exige une troisième (temp).
Lire de droite à gauche
Affectation : calcule à droite, range à gauche.
Nommer, c'est déjà programmer
Un nom de variable dit ce qu'il contient (underscore, pas d'espace).
Où va l'ancienne valeur ?
Affecter écrase : pour garder, recopier AVANT.
Suivre à la trace
La table de suivi est le multimètre du programmeur.
Le vrai sens du signe =
= affecte (range) ; == compare.
