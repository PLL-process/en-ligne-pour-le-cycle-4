📄 Synthèse — La boîte étiquetée

5e_C9.1 → C9.3 · Thème 3 · New York — ce qu'il faut savoir refaire

📦 La variable (5e_C9.1)

  • Une variable = une boîte de la mémoire : une ÉTIQUETTE (son nom) + UNE seule valeur.
  • Le signe = veut dire « RANGE cette valeur dans la boîte » — et il remplace l'ancienne (perdue !).
  • places = places - montes se lit de droite à gauche : je calcule d'abord, je range ensuite.
  • total = total + 2 répété = le motif compteur (la boîte accumule).
  • Pour lire un programme : la table de suivi — une colonne par boîte, le doigt qui suit ligne par ligne.
  • Piège : entre guillemets, "20" + "4" donne "204" — du TEXTE collé, pas une addition !

🔎 Lire et TESTER un programme fourni (5e_C9.1)

  • Tester = comparer : ce que le besoin ATTEND ↔ ce que la console DONNE, sur plusieurs cas.
  • UN SEUL test raté suffit : le programme ne répond pas au besoin (le bug du Cyclone dormait jusqu'au premier visiteur qui descend…).
  • L'ordinateur obéit au PROGRAMME, pas au besoin : un écart accuse une ligne — à trouver avec la table de suivi.
  • Le bon diagnostic se communique : comportement + ligne coupable + test qui le prouve.

🔧 Modifier et régler (5e_C9.2 · C9.3)

  • Modifier = changer LA bonne ligne (le nombre de sièges n'est écrit qu'à UN endroit : c'est la force des variables) — puis REJOUER TOUS les tests (la non-régression).
  • La condition SI places > 0 → OUVRIR sinon FERMER : le programme lit une boîte et décide.
  • LE test le plus important : la FRONTIÈRE (places = 0 pile). 0 > 0 est FAUX → barrière FERMÉE : c'est ce qu'on veut. Avec >=, le visiteur de trop entrerait !
  • Ta variable commande un objet réel : compteur → programme → moteur de la barrière — l'information en haut, l'énergie en bas, l'ordre qui descend (📐 règle du schéma).
  • Réglé = tous les tests verts, frontière comprise — pas « ça a marché une fois ».

🎯 En une phrase

Une variable est une boîte étiquetée que le = remplit ; lire un programme, c'est suivre les boîtes ; le tester, c'est comparer attendu et obtenu ; et il n'est réglé que quand tous les tests passent — le cas frontière en premier.
