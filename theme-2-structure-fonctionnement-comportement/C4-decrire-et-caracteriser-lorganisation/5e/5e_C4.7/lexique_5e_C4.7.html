C4.7 · 16 notions

Les 24 prises
Un commutateur possède un nombre limité de prises (ici 24) : une prise = un câble = un appareil.
L'avantage de l'étoile
En étoile, une branche cassée n'isole QU'UN terminal — les autres continuent.
Le bon câble
Terminal ↔ commutateur = câble cuivre droit (Copper Straight-Through).
Compter les terminaux
Pour compter les terminaux : je garde les appareils qui envoient ou reçoivent, j'écarte commutateur et point d'accès.
L'imprimante
Un terminal peut surtout RECEVOIR : l'imprimante est le terminal-réception type.
L'opération module WiFi
Changer un module : ÉTEINDRE → échanger → RALLUMER. Toujours.
Le point d'accès
Point d'accès = le pont entre les terminaux sans fil et le réseau câblé.
La prise du PC
La prise réseau d'un PC s'appelle FastEthernet0 — retiens « Ethernet » = réseau filaire.
Qu'est-ce qu'un terminal
Terminal = appareil qui envoie ou reçoit des messages (PC, imprimante, tablette, smartphone…).
Reconnaître le commutateur
Le commutateur = le boîtier central du réseau filaire, le « facteur » qui redistribue les messages.
Le rôle du commutateur
Le commutateur lit l'ADRESSE DE DESTINATION et choisit la bonne branche — rien d'autre.
Le smartphone, un terminal ?
Tout appareil qui envoie/reçoit sur le réseau est un terminal — le smartphone aussi.
Le SSID
SSID = le nom du réseau WiFi, diffusé par le point d'accès.
La topologie en étoile
Topologie = la forme du réseau. Tout passe par le centre → topologie en ÉTOILE.
Traits pleins, pointillés
Trait plein = liaison filaire · pointillés = liaison sans fil (WiFi).
Les triangles
Triangles : orange = démarre · vert = ça marche · rouge = problème.

C4.8 · 14 notions

À quoi sert le ping
ping = le test de livraison : messages envoyés, réponses chronométrées.
Câble contre WiFi
Filaire : rapide et régulier. WiFi : pratique mais plus lent et variable. Les deux livrent.
La case mystère
Subnet Mask : la case qui se remplit seule. On la laisse — rendez-vous en 4e.
Choisir une adresse
Nouvelle adresse = même rue + numéro libre. Jamais de numéro déjà pris.
La démarche complète
La démarche : découvrir en débranché → vérifier en simulation. C'est la compétence 5e_C4.8 entière.
Le doublon du facteur
Un doublon d'identification = une livraison qui n'est plus fiable.
Le doublon, version réseau
Une adresse = UN terminal. Le doublon casse la fiabilité de la livraison.
L'enveloppe sans nom
Tout message porte l'identification de son destinataire — sinon, pas de livraison.
Éteint mais adressé
Éteindre ne libère pas l'adresse : on ne « prête » jamais une adresse déjà attribuée.
Lire la fenêtre
L'adresse du terminal se lit dans le champ IPv4 Address.
Lire une adresse IP
Adresse IP = rue commune (3 premiers nombres) + numéro de maison unique (dernier nombre).
Où taper l'adresse
Adresse IP d'un terminal : Desktop → IP Configuration → Static.
Reply from
« Reply from » = aller-retour réussi · « Request timed out » = pas de réponse.
Le trajet de l'enveloppe
Event List = le film du trajet : terminal → commutateur → terminal.
