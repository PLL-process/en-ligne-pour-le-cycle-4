💡 Synthèse — Le lampadaire intelligent

Comment un objet technique capte, décide, agit — et comment on le décrit avec des données ?

1. Fonctions et solutions techniques (5e_C4.1) · Matériaux (5e_C4.4)

Une fonction technique = CE QUE l'objet doit faire (« éclairer », « stocker l'énergie »). Une solution technique = l'ÉLÉMENT choisi pour le faire (bloc de LED, batterie). Une même fonction peut avoir plusieurs solutions : on choisit selon des critères (consommation, coût, durée de vie, environnement). Chaque matériau est choisi pour ses propriétés : acier galvanisé (mât : solide, traité anti-rouille), polycarbonate (vitre : transparent, très résistant), aluminium (léger, ne rouille pas), cuivre (câbles : excellent conducteur, gainé d'isolant).

2. Les DEUX chaînes de l'objet (5e_C4.2, C4.3, C4.5)

Chaîne d'ÉNERGIE : panneau solaire (capter + convertir) → batterie (stocker) → régulateur + interrupteur (distribuer) → bloc LED (convertir). Natures d'énergie : lumineuse → électrique → chimique → électrique → lumineuse. Chaîne d'INFORMATION : capteurs (acquérir) → carte électronique (traiter : SI nuit ET passage → allumer fort) → ordre au bloc LED (commander). L'information commande l'énergie : l'énergie fait fonctionner, l'information rend « intelligent ».

3. Décrire par des données (5e_C4.6)

Descripteur
une caractéristique choisie pour décrire l'objet : numero, batterie_pct, etat, annee_pose…
Type
nombre, texte, date, vrai/faux — il dit ce qu'on a le droit de faire (calculer, trier…).
Format
la règle d'écriture : batterie_pct = nombre entier de 0 à 100, sans unité écrite.

Dans un tableau : une ligne = un objet complet, une colonne = un descripteur. Des données bien décrites peuvent être triées, comparées, transmises.

4. Le réseau local (5e_C4.7, C4.8)

Composants
terminaux (PC, tablettes, imprimante), commutateur (relie tout le monde), borne Wi-Fi (accès sans fil), serveur (stocke les dossiers) ; liaisons filaires (câbles) et sans fil.
Identification
pour communiquer, chaque terminal doit avoir un nom et une adresse UNIQUES — comme un courrier : sans destinataire unique, impossible de livrer !

✅ Je dois savoir

  • distinguer fonction technique et solution technique ;
  • citer les blocs des deux chaînes et la nature des énergies à chaque étape ;
  • associer un matériau à une propriété utile (anti-rouille, conducteur, transparent…) ;
  • définir descripteur, type et format d'une donnée ;
  • nommer les composants d'un réseau local et expliquer pourquoi on identifie les terminaux.

🛠 Je dois savoir faire

  • annoter un objet réel : fonctions ↔ solutions ↔ matériaux ;
  • compléter une chaîne d'énergie ou d'information FOURNIE ;
  • prédire le comportement du lampadaire (jour / nuit / nuit + passage) ;
  • lire et compléter un tableau de descripteurs, choisir un bon format ;
  • retrouver le chemin d'un message sur le schéma du réseau du collège.

⚠ Erreurs à éviter

  • Confondre fonction (ce qu'il faut faire) et solution (l'élément choisi) ;
  • croire que la batterie « fabrique » de l'énergie : elle la stocke (sous forme chimique) ;
  • mettre la LED dans la chaîne d'information : elle reçoit l'ordre, elle ne décide pas ;
  • écrire un descripteur flou (« batterie » sans type ni format : 12 ? 12 % ? faible ?) ;
  • confondre commutateur (relie en filaire) et borne Wi-Fi (accès sans fil) ;
  • donner le même nom à deux terminaux : le réseau ne sait plus à qui livrer.
