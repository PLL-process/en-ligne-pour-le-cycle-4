# 5e_C4.8 — ressource mutualisée (atelier réseau dédié 5e_C4.7)

**Justifier la nécessité d'identifier les terminaux pour communiquer sur un réseau local
(activité débranchée et vérification par un outil de simulation).**

Cette sous-compétence est traitée dans l'**atelier « Le réseau de la salle techno »**
(5e_C4.7 + 5e_C4.8), qui suit littéralement le libellé du programme : jeu du facteur
débranché (act. 1), adressage IP (act. 4), puis vérification par simulation — ping,
enveloppe du mode Simulation, panne du doublon d'adresse dans Cisco Packet Tracer 8.2 et
mini-simulateur intégré à verrou expérientiel (act. 5). 14 questions dédiées au QCM.
