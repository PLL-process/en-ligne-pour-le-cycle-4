Les questions ciblent 4e_C4.4 (constituants de la chaîne d'information d'un objet réel), avec des liens vers C4.1 et C6.2.

Quelle est la première étape de la chaîne d'information ?

Compétence visée : 4e_C4.4 (1 pt)
La chaîne d'information commence toujours par ACQUÉRIR : un capteur transforme une grandeur physique (choc, position…) en signal exploitable.

Quel élément acquiert les données dans le système eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Le capteur est l'organe d'acquisition. La carte SIM sert à communiquer, la batterie à alimenter.

Quel capteur détecte un accident ?

Compétence visée : 4e_C4.4 (1 pt)
L'accéléromètre mesure les variations brutales de vitesse : une décélération violente signale un choc.

Que fait le GPS ?

Compétence visée : 4e_C4.4 (1 pt)
Le récepteur GPS/GNSS calcule la position du véhicule grâce aux satellites — indispensable pour guider les secours.

Le eCall peut-il fonctionner automatiquement ?

Compétence visée : 4e_C4.4 (1 pt)
En cas de choc grave (déclenchement des airbags), l'appel part automatiquement, sans action du conducteur.

Dans la chaîne d'information, quel élément TRAITE les données du eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Le calculateur embarqué analyse les signaux des capteurs et décide de déclencher (ou non) l'appel d'urgence.

Quel élément COMMUNIQUE l'alerte vers l'extérieur ?

Compétence visée : 4e_C4.4 (1 pt)
Le module de téléphonie mobile (avec sa carte SIM intégrée) transmet l'appel et les données au centre de secours.

Cite dans l'ordre les 3 grandes fonctions de la chaîne d'information (mots-clés).

Compétence visée : 4e_C4.4 (1 pt)
Acquérir (capteurs) → Traiter (calculateur) → Communiquer (module GSM). C'est le squelette de toute chaîne d'information.

Quel numéro d'urgence européen le eCall compose-t-il ?

Compétence visée : 4e_C4.4 (1 pt)
Le 112 est le numéro d'urgence unique européen, valable dans toute l'Union européenne.

Depuis quelle année le eCall est-il obligatoire sur les nouveaux modèles de voitures vendus dans l'UE ?

Compétence visée : 4e_C4.4 (1 pt)
Le règlement européen impose le eCall sur les nouveaux modèles homologués depuis le 31 mars 2018.

Comment le conducteur peut-il déclencher le eCall manuellement ?

Compétence visée : 4e_C4.4 (1 pt)
Un bouton SOS (souvent au plafonnier) permet de déclencher l'appel même sans choc, par exemple pour un malaise.

Coche les données transmises automatiquement par le eCall (jeu de données minimal).

Compétence visée : 4e_C4.4 (1 pt)
Le MSD (Minimum Set of Data) contient position, heure, direction, identification du véhicule… mais aucune donnée sans rapport avec le secours.

Que signifie MSD dans le contexte du eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Le MSD est le paquet de données normalisé envoyé au centre d'appel : position, heure, type de déclenchement…

Quel événement déclenche automatiquement le eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Les capteurs de choc liés aux airbags servent de déclencheur : si les airbags partent, l'appel part.

Après l'envoi des données, que permet aussi le eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Le haut-parleur et le micro de l'habitacle ouvrent une liaison vocale : l'opérateur du 112 peut parler aux occupants.

Dans le eCall, le haut-parleur et le micro appartiennent plutôt à…

Compétence visée : 4e_C4.4 (1 pt)
Micro et haut-parleur permettent le dialogue humain ↔ machine/secours : c'est l'IHM du système.

Le eCall nécessite-t-il un abonnement téléphonique du conducteur ?

Compétence visée : 4e_C4.4 (1 pt)
La carte SIM est intégrée au véhicule et l'appel au 112 est gratuit : aucun abonnement personnel n'est requis.

En dehors d'un accident, le eCall…

Compétence visée : 4e_C4.4 (1 pt)
Par respect de la vie privée, le système est « dormant » : il ne communique qu'en cas de déclenchement.

Principal intérêt du eCall pour les secours :

Compétence visée : 4e_C4.4 (1 pt)
Localisation immédiate = intervention plus rapide, surtout la nuit ou en zone rurale, quand personne ne peut alerter.

Quelle constellation européenne de satellites peut fournir la position au eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Galileo est le système de navigation par satellites de l'Union européenne, utilisé en complément du GPS américain.

Coche les éléments qui appartiennent à la chaîne d'INFORMATION du eCall.

Compétence visée : 4e_C4.4 (1 pt)
Capteurs (accéléromètre, GPS), traitement (calculateur) et communication (GSM) = chaîne d'information. La batterie relève de la chaîne d'énergie.

La batterie du véhicule joue quel rôle pour le eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Sans énergie, pas d'information : la batterie alimente capteurs, calculateur et module de communication.

Pourquoi le eCall dispose-t-il souvent d'une batterie de secours ?

Compétence visée : 4e_C4.4 (1 pt)
Un accident grave peut couper l'alimentation principale : la batterie de secours garantit l'appel d'urgence.

Le signal issu de l'accéléromètre est d'abord…

Compétence visée : 4e_C4.4 (1 pt)
Le capteur transforme la décélération (grandeur physique) en signal électrique que le calculateur peut traiter.

Quel composant identifie le véhicule dans les données envoyées ?

Compétence visée : 4e_C4.4 (1 pt)
Le VIN (Vehicle Identification Number) permet aux secours de connaître le modèle exact du véhicule accidenté.

Vrai ou faux : le eCall peut aussi être déclenché par un témoin depuis un autre véhicule équipé.

Compétence visée : 4e_C4.4 (1 pt)
Le bouton SOS permet un déclenchement manuel : un témoin d'accident peut alerter le 112 depuis son propre véhicule.

Où sont reçues les données du eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Le PSAP (Public Safety Answering Point) est le centre 112 qui reçoit l'appel et coordonne les secours.

Le trajet « capteur → calculateur → module GSM → antenne » illustre…

Compétence visée : 4e_C4.4 (1 pt)
C'est le flux d'information : acquisition, traitement, puis communication vers l'extérieur.

Quelle grandeur mesure l'accéléromètre ?

Compétence visée : 4e_C4.4 (1 pt)
Accéléromètre = capteur d'accélération. Une forte décélération (choc) déclenche l'alerte.

Sans réseau mobile disponible, le eCall…

Compétence visée : 4e_C4.4 (1 pt)
Le module GSM a besoin d'une couverture mobile. C'est une limite du système dans les zones blanches.

Classer eCall parmi les objets suivants : c'est un…

Compétence visée : 4e_C4.4 (1 pt)
Le eCall est un système électronique embarqué dans le véhicule, qui communique avec l'extérieur : un objet communicant.

Coche les situations où le eCall se déclenche.

Compétence visée : 4e_C4.4 (1 pt)
Deux déclencheurs seulement : automatique (choc grave) ou manuel (bouton SOS).

Quel capteur donne la POSITION du véhicule ? (mot-clé)

Compétence visée : 4e_C4.4 (1 pt)
Le récepteur GPS/GNSS (dont Galileo) calcule la position par satellites.

La communication du eCall vers le 112 passe par…

Compétence visée : 4e_C4.4 (1 pt)
L'appel et le MSD transitent par le réseau mobile, comme un appel téléphonique classique.

Quelle information N'EST PAS transmise par le eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Le MSD est minimal et strictement lié au secours : aucune donnée de navigation personnelle n'est envoyée.

Le nombre d'occupants peut être estimé grâce…

Compétence visée : 4e_C4.4 (1 pt)
Les capteurs de ceinture donnent une estimation du nombre de personnes à secourir — précieuse pour dimensionner les secours.

Dans un algorigramme du eCall, le test « choc détecté ? » se représente par…

Compétence visée : 4e_C4.4 (1 pt)
Le losange représente toujours une décision/condition dans un algorigramme.

Si « choc détecté = FAUX », que fait le programme du eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Tant qu'aucun choc n'est détecté, le système boucle sur la surveillance des capteurs : c'est une boucle d'attente d'événement.

Le eCall améliore surtout la sécurité…

Compétence visée : 4e_C4.4 (1 pt)
Le eCall n'évite pas l'accident : il réduit le délai d'arrivée des secours, ce qui sauve des vies après le choc.

Quel domaine du socle est le plus mobilisé quand tu décris la chaîne d'information du eCall ?

Compétence visée : 4e_C4.4 (1 pt)
Décrire l'organisation interne d'un système technique relève du domaine 4 du socle commun.
