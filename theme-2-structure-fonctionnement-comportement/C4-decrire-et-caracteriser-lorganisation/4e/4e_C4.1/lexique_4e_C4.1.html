Fonction de la batterie
Batterie = STOCKER (énergie chimique, restituée à la demande).
Fonction du panneau
Panneau solaire = ALIMENTER (convertit lumineuse → électrique).
Le pont entre chaînes
Dans un système automatisé, l'information COMMANDE l'énergie via la carte.
Stockage ou transformation ?
Stocker ≠ convertir : la batterie est un réservoir.
Trajet complet
Suivre la chaîne bloc par bloc = lire le trajet des natures d'énergie.
Transformation dans la pompe
Pompe = CONVERTIR (électrique → mécanique).
Les trois flux
Trois flux à distinguer : énergie, matière (eau), information.

La colonne capteur
La colonne d'identification permet filtres et comparaisons.
Donnée fiable ?

L'horodatage
Donnée utile = valeur + horodatage + identification de la source.
Une ligne de la table

Lire un arrosage

Objet connecté

Trier, filtrer, tracer

Adresse IP
IP = adresse unique d'un appareil sur le réseau.
Choisir une IP fixe
IP fixe : libre + hors plage DHCP.
Conflit d'adresses
Une IP = un seul appareil. Doublon = conflit = communication cassée.
Diagnostiquer avec méthode
Diagnostic réseau : un test à la fois — portée, adresses, passerelle.
Hors de portée
Dépannage réseau : vérifier D'ABORD la portée et la liaison physique.
La passerelle
Passerelle = l'adresse de la box, porte de sortie du réseau.
Pourquoi DHCP
Client qui appelle = DHCP · service qu'on appelle = IP fixe.
Pourquoi IP fixe
Objet à joindre = IP fixe, connue de tous ses clients.
Réseau local vs internet
192.168.x.x = adresses locales ; la passerelle fait le lien vers l'extérieur.
La simulation
Simuler = expérimenter les pannes sans risque, avant le réel.
