C4.3 · 8 notions

Chaîne info vs chaîne énergie
Deux chaînes distinctes : la chaîne d'ÉNERGIE alimente, la chaîne d'INFORMATION mesure, décide, prévient.
Définition de la chaîne
À chaque bloc de la chaîne, la NATURE du signal change ; l'information portée reste la même.
Fonction Communiquer
COMMUNIQUER = diffuser l'information par tout canal : radio, son, lumière, écran, application.
Lire un schéma bloc
Schéma bloc = blocs fonctionnels + flèches de flux d'information étiquetées par la nature du signal.
Nature des signaux
Capteur : grandeur physique EN ENTRÉE → signal électrique EN SORTIE.
Ordre des fonctions
Chaîne d'information = ACQUÉRIR → TRAITER → COMMUNIQUER, toujours dans cet ordre.
Rôle du microcontrôleur
TRAITER = appliquer le programme et ses seuils pour transformer des mesures en décision.
Transfert à un autre OST
Dans TOUT objet connecté on retrouve Acquérir (capteur) / Traiter (processeur + programme) / Communiquer (vibreur, écran, radio).

C4.4 · 8 notions

Analogique vs numérique
Analogique = continu (infinité de valeurs) · Numérique = discret (paliers en nombre limité).
Calcul de conversion
valeur = min + N × (étendue ÷ (2ⁿ − 1)) : toujours convertir N avant de l'interpréter.
CAN 8 bits (transfert)
La formule de conversion s'adapte à chaque CAN : identifier d'abord n (bits), le min et l'étendue.
Choix du nombre de bits
Nombre de bits du CAN = compromis précision / coût / poids des données.
Nombre de paliers
n bits → 2ⁿ valeurs, numérotées de 0 à 2ⁿ − 1.
Précision du convertisseur
Précision d'un CAN = étendue de mesure ÷ (2ⁿ − 1).
Valeur maximale
Sortie d'un CAN n bits : de 0 à 2ⁿ − 1 (10 bits : 0 à 1023).
Vocabulaire CAN
CAN = Convertisseur Analogique → Numérique (ADC en anglais) : tension continue → nombre entier.

C4.5 · 8 notions

Choisir un descripteur
Descripteur : explicite + unité + sans espace ni accent (ex. vent_kmh, pression_hpa).
Coder en binaire
Binaire : positions = puissances de 2 (…, 4, 2, 1). Un code n'a de sens qu'avec sa table de correspondance.
Dimensionner un codage
Pour V valeurs : chercher le plus petit n tel que 2ⁿ ≥ V.
Notion d'enregistrement
Table structurée = descripteurs en colonnes + enregistrements en lignes, horodatés.
Puissances de 2
n bits → 2ⁿ combinaisons : 1 bit → 2, 2 bits → 4, 3 bits → 8, 4 bits → 16.
Représenter diverses natures
Toute information (mesure, lieu, état, instant) peut être représentée par une donnée du type adapté.
Le type booléen
Booléen = deux valeurs seulement (vrai/faux) : parfait pour les états binaires.
Types de données
Choisir le type selon la nature de l'information : entier, décimal, texte, booléen, date.

C4.6 · 8 notions

Choisir selon l'usage
.pdf = document à mise en page figée, idéal pour diffuser et imprimer à l'identique.
Format tableau
Données tabulaires → .csv (ou .ods/.xlsx) : des valeurs qu'on peut trier, filtrer, calculer.
Mise en forme
Mise en forme = structurer la donnée dans un format adapté (csv, json, png, mp3, pdf…).
Nature → format
Chaque nature d'information a ses formats : tableau .csv · image .png/.svg · son .mp3 · message structuré .json · document .pdf.
Poids et compression
Compresser = réduire le poids du fichier pour transmettre plus vite et stocker moins — un compromis poids/qualité.
Redondance de stockage
Redondance = stocker en deux endroits indépendants pour résister aux pannes et coupures.
Rôle du serveur
Serveur = ordinateur qui stocke les fichiers et les met à disposition des terminaux via le réseau.
Transmission = copie
Transmettre = copier vers un autre équipement ; l'original reste en place.
