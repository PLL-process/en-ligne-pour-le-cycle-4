🌀 Synthèse — Station d'alerte cyclonique connectée

Comment la station transforme-t-elle des grandeurs physiques en données numériques fiables, afin de déclencher l'alerte au bon moment ?

1. La chaîne d'information (3e_C4.3)

ACQUÉRIR (capteurs) → TRAITER (microcontrôleur + seuils du programme) → COMMUNIQUER (antenne, sirène, application). À chaque étape, la nature du signal change : grandeur physique → signal électrique → donnée numérique → message. La chaîne d'énergie (panneau solaire, batterie) alimente sans transporter d'information.

2. Le CAN (3e_C4.4)

CAN (angl. ADC)
Convertisseur Analogique → Numérique : tension continue → nombre entier.
n bits → 2ⁿ paliers
10 bits → 1024 valeurs (0 à 1023) ; 8 bits → 256 (0 à 255).

valeur = min + N × (étendue ÷ (2ⁿ − 1))

Exemple : baromètre 868–1018 hPa, N = 512 → 868 + 512 × 0,147 ≈ 943 hPa.

3. Les données (3e_C4.5)

Type
entier (132), décimal (987.4), texte ("Sainte-Luce"), booléen (vrai/faux), date+heure.
Descripteur
nom de colonne explicite, sans espace ni accent : vent_kmh.
Enregistrement
une ligne = toutes les données d'un même instant.
Codage binaire
n bits → 2ⁿ valeurs. 5 niveaux de vigilance → 3 bits (2³ = 8 ≥ 5).

4. Fichiers : mise en forme, transmission, stockage (3e_C4.6)

Mise en forme = choisir le format selon la nature : tableau → .csv/.ods · message structuré → .json · image → .png/.svg · son → .mp3 · document figé → .pdf. Transmettre = copier vers un autre équipement (l'original reste !). Stocker = conserver — en double si possible (redondance : carte mémoire + serveur) pour résister aux coupures.

✅ Je dois savoir

  • citer les 3 fonctions de la chaîne d'information et leurs constituants ;
  • expliquer analogique (continu) / numérique (paliers) ;
  • la formule du CAN et 2ⁿ ;
  • les 5 types de données et le rôle d'un descripteur ;
  • transmission = copie · stockage = conservation · redondance.

🛠 Je dois savoir faire

  • décrire la chaîne d'info d'un objet connecté inconnu ;
  • convertir N ↔ valeur physique (10 bits, 8 bits) ;
  • typer une donnée et choisir un bon descripteur ;
  • coder une valeur en binaire et dimensionner (2ⁿ ≥ V) ;
  • choisir un format de fichier et le justifier ;
  • exploiter une table de mesures (MIN, MAX, durées).

⚠ Erreurs à éviter

  • Classer le panneau solaire dans la chaîne d'information (il capte de l'énergie) ;
  • 1023 paliers au lieu de 1024 — et N max = 1023, jamais 1024 ;
  • « 12 bits pour 12 niveaux » : on compte les combinaisons (2ⁿ ≥ V) ;
  • croire qu'un fichier transmis est déplacé : il est copié ;
  • stocker un tableau de nombres en image (.png) : plus aucun calcul possible.
