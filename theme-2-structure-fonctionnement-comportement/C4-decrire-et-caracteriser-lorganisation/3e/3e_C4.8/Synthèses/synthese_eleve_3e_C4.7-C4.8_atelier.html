📌 Synthèse élève — Le pont numérique Martinique → New York

Faire communiquer deux réseaux, et prouver que le message arrive.

🧠 Ce que je dois retenir

Comment deux réseaux différents se parlent-ils, et pourquoi Internet a-t-il besoin d'un protocole de routage ?

Ce que dit le programme (3e, compétence C4) :
  • identifier et représenter la circulation d'une information dans le réseau Internet ;
  • justifier la nécessité d'un protocole de routage pour faire communiquer plusieurs réseaux (activité débranchée, table de routage donnée).
🚧 1. Pourquoi un commutateur ne suffit-il pas ? Il ne connaît que sa rue. Pour en sortir, il faut un routeur. 🌉 2. Comment dessiner le pont entre deux réseaux ? Un routeur à chaque porte, une rue-pont entre les deux : trois réseaux. 🛃 3. Que fait le routeur à la frontière ? Il lit sa table : transmettre, distribuer ou détruire. 🧰 4. Comment construire le pont dans le logiciel ? Un câble croisé, des prises allumées, et une route dans chaque sens. 🧾 5. Comment prouver le voyage ? Le ping répond, le TTL compte les routeurs, le tracert montre le chemin. 📜 6. Pourquoi un protocole de routage est-il nécessaire ? Sans table, aucun message ne passe. Internet est trop grand pour des tables écrites à la main.
↑ La carte

1. Pourquoi un commutateur ne suffit-il pas ?

Le PC de la Martinique habite la rue 192.168.10 ; le serveur de New York, la rue 192.168.30.

Le masque 255.255.255.0Les trois premiers nombres disent la rue ; le dernier, la maison.
✘ Un très long câbleLe commutateur ne connaît que sa rue : il ne sait pas en sortir.
✔ Un routeur à chaque porteIl fait passer les messages d'un réseau à l'autre.

🧠 À retenir : le commutateur distribue dans un réseau. Le routeur fait passer les messages d'un réseau à l'autre : c'est le poste-frontière.

⚠️ Le piège : relier directement les deux commutateurs. Sans poste-frontière, les deux rues ne se parlent pas.

↑ La carte

2. Comment dessiner le pont entre deux réseaux ?

Avant d'ouvrir le logiciel, tu as conçu le pont en quatre étapes :

1. Deux rues192.168.10 pour la Martinique, 192.168.30 pour New York.
2. Deux routeursR-MQ et R-NY, un à la porte de chaque quartier.
3. La rue-pont10.0.0.x entre les routeurs : R-MQ au .1, R-NY au .2.
4. Les commutateursIls restent dans leur quartier et y distribuent.

Ta passerelle de 4e a maintenant un corps : c'est le pied « quartier » du routeur, le .1 de sa rue.

🧠 À retenir : pour relier deux réseaux, il faut un routeur à la porte de chacun et une rue-pont entre les deux. Le montage compte donc trois réseaux.

⚠️ Le piège : donner une seule adresse au routeur. Il en a une par réseau où il a un pied : 192.168.10.1 et 10.0.0.1 pour R-MQ.

↑ La carte

3. Que fait le routeur à la frontière ?

Au jeu du poste-frontière, tu es R-MQ. Ta table dit « 192.168.30.0 via 10.0.0.2 ». Trois enveloppes arrivent :

Pour 192.168.30.10La rue est dans ma table : je transmets via 10.0.0.2, sur le pont.
Pour 192.168.10.20Une rue directement connectée : je distribue dans le quartier.
Pour 192.168.50.7Une rue inconnue : je détruis le paquet.

🧠 À retenir : le routeur lit l'adresse de destination, puis applique sa table de routage. Il n'envoie jamais un paquet au hasard.

⚠️ Le piège : croire que le routeur « essaie quand même ». Une rue inconnue donne un paquet détruit : c'est la règle, pas une panne.

4. Comment construire le pont dans le logiciel ?

Dans Packet Tracer, quatre gestes font monter le pont :

Le câble croiséEntre les deux routeurs. Partout ailleurs, des câbles droits.
La case « On »Les prises d'un routeur naissent éteintes. On les allume.
La route statiqueSur R-MQ : réseau 192.168.30.0, prochain saut 10.0.0.2.
La route miroirSur R-NY : réseau 192.168.10.0, prochain saut 10.0.0.1.

🧠 À retenir : une route statique est une ligne de table écrite à la main : « tel réseau étranger, via tel prochain saut ». Chaque sens du voyage a besoin de sa route.

⚠️ Le piège : oublier la route miroir dans R-NY. L'aller connaît le chemin, mais la réponse ne trouve pas le retour.

↑ La carte

5. Comment prouver le voyage ?

Sur PC-MQ, nos preuves ont été mesurées dans le vrai logiciel :

pingDeux échecs, puis des réponses. Relancé : 0 % de perte.
TTL=126Il part de 128, et chaque routeur retire 1 : deux routeurs traversés.
tracert192.168.10.1 ➜ 10.0.0.2 ➜ 192.168.30.10 : trois sauts, sans les commutateurs.
La simulationSaut par saut, de 0,000 à 0,010 seconde. Verdict : Successful.

🧠 À retenir : le ping prouve l'aller-retour. Le tracert montre le chemin, routeur par routeur ; le TTL compte les frontières franchies.

⚠️ Le piège : conclure à une panne après les deux premiers échecs du ping. Au premier voyage, chaque appareil cherche encore ses voisins : on relance d'abord.

↑ La carte

6. Pourquoi un protocole de routage est-il nécessaire ?

L'expérience décisive : on efface une seule ligne de la table de R-MQ, puis on renvoie le message.

✔ Avec la ligneLe message arrive au serveur de New York, et la réponse revient.
✘ Sans la ligneLe message est détruit à R-MQ, dès la première frontière.
À l'échelle d'InternetDes centaines de milliers de réseaux, qui changent sans cesse.

🧠 À retenir : sans table de routage, aucun message ne passe d'un réseau à l'autre. À l'échelle d'Internet, seul un protocole de routage, où les routeurs s'informent entre eux, peut remplir les tables : il est nécessaire.

⚠️ Le piège : répondre « c'est automatique » sans dire pourquoi. Il faut l'argument du nombre : tant de tables ne peuvent pas s'écrire à la main.

📖 Les mots de la séquence

réseau — network
des appareils de la même « rue », qui se parlent directement.
masque — subnet mask
il dit quelle partie de l'adresse est la rue.
commutateur — switch
il distribue les messages dans un réseau.
routeur — router
le poste-frontière entre deux réseaux.
passerelle — gateway
l'adresse du routeur côté quartier, le .1.
rue-pont — link network
le petit réseau qui relie les deux routeurs.
câble croisé — crossover cable
le câble entre deux appareils de même famille.
table de routage — routing table
les lignes « réseau de destination ➜ prochain saut ».
route statique — static route
une ligne de table écrite à la main.
saut — hop
le passage d'un routeur au suivant.
paquet — packet
un morceau de message, avec ses adresses.
ping — ping
la commande qui teste l'aller-retour.
TTL — time to live
un compteur : chaque routeur lui retire 1, et à 0 le paquet est détruit.
tracert — traceroute
la commande qui liste les routeurs traversés.
protocole de routage — routing protocol
des règles pour que les routeurs s'informent et remplissent leurs tables.
