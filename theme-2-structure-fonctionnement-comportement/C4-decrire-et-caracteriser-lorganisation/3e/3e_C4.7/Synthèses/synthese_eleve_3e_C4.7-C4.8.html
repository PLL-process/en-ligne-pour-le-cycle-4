🌐 Synthèse — Internet jusqu'à Sainte-Luce

Comment l'information circule-t-elle de réseau en réseau, et pourquoi arrive-t-elle même quand une route est coupée ?

1. Du réseau local à Internet (3e_C4.7)

Réseau local = terminaux + commutateur (relie à l'intérieur) + routeur (porte de sortie vers les autres réseaux). Chaque équipement a une adresse IP unique. Internet = le réseau des réseaux : une information traverse une succession de réseaux (local → opérateur → câbles sous-marins → destinataire). ~99 % du trafic intercontinental passe par des câbles sous-marins — vitaux pour la Martinique.

2. Les paquets (3e_C4.7)

Découpage
tout message est découpé en paquets numérotés.
En-tête
IP destination + IP source + numéro d'ordre (l'« enveloppe »).
Voyage
routes parfois différentes, arrivée parfois dans le désordre.
Réassemblage
grâce aux numéros ; un paquet perdu est redemandé seul.

3. Le routage (3e_C4.8)

Table de routage
règles « réseau de destination → prochaine sortie » ; route par défaut pour le reste.
Saut par saut
chaque routeur ne décide que du prochain saut.
Mise à jour automatique
les routeurs s'annoncent les routes ; une panne est contournée.
Protocole commun
règles partagées par TOUS les réseaux — sans elles, pas d'Internet.

✅ Je dois savoir

  • définir terminal, commutateur, routeur, adresse IP, paquet, table de routage, protocole ;
  • expliquer « Internet = réseau de réseaux » ;
  • expliquer pourquoi un protocole de routage commun est indispensable ;
  • expliquer la résilience (maillage + tables mises à jour) et sa limite (réseau isolé).

🛠 Je dois savoir faire

  • représenter le trajet d'une information par un schéma fléché légendé ;
  • appliquer une table de routage à des paquets ;
  • calculer un nombre de paquets (taille ÷ taille d'un paquet) ;
  • prévoir le comportement du réseau après une coupure.

⚠ Erreurs à éviter

  • Confondre Wi-Fi (accès local sans fil), Internet (réseau mondial) et Web (un service d'Internet) ;
  • croire que le trafic intercontinental passe par satellite (→ câbles sous-marins !) ;
  • croire que tous les paquets suivent le même chemin, ou qu'une perte oblige à tout renvoyer ;
  • confondre panne (route coupée) et congestion (route saturée → lenteur) ;
  • croire que le routage peut joindre un réseau physiquement isolé.
