# Vittascience cycle 4 – Variables, types et systèmes programmés

Fichier HTML interactif pour une séance/évaluation de technologie cycle 4.

## Contenu

* Questionnaire avec aides et corrections.
* Correction affichée = points retirés pour la question.
* Choix du temps : standard, tiers-temps, sans chrono.
* Chronomètre indicatif et non bloquant.
* Sauvegarde automatique locale.
* Export des réponses en JSON.
* Images externalisées dans `assets/` pour alléger le HTML.
* Mode enseignant : code `GJEP`.

## Publication GitHub Pages

Déposer `index.html` et le dossier `assets/` à la racine du dépôt, puis activer GitHub Pages.

## Version v3

* Ajout de panneaux pliables d’expérimentation Vittascience dans les exercices concernés.
* Interface Python intégrée pour les exercices variables/types.
* Interface Arduino intégrée pour l’exercice d’arrosage automatique.

## Version v4 vidéo immersive

* Vidéo YouTube intégrée derrière un bouton `<details>`.
* Consigne explicite avant la vidéo.
* Bouton d’ouverture dans un nouvel onglet.
* Intégration responsive tablette / ordinateur.
* Mini-quiz vidéo non noté.
