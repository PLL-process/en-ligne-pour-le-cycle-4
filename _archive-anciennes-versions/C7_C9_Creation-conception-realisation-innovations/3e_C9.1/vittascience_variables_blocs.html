Fiche méthode : trouver la valeur d’une variable

Pour trouver la valeur d’une variable : lire les lignes dans l’ordre, remplacer les variables par leurs valeurs, calculer, retenir la dernière valeur.
  1. Lire les lignes dans l’ordre : un programme en blocs se lit de haut en bas, bloc après bloc.
  2. Remplacer les variables par leurs valeurs : si le bloc dit « affecter à x la valeur 7 », alors on utilise 7 quand on voit x dans un calcul.
  3. Calculer étape par étape : faire d’abord les multiplications, puis les additions ou soustractions.
  4. Retenir la dernière valeur : si une variable reçoit une nouvelle valeur, l’ancienne valeur est remplacée.

Mini-cours : variables, nombres entiers, nombres décimaux et textes

Une variable mémorise une information. Avec les blocs, on lui donne une valeur grâce au bloc rouge affecter à … la valeur.

Ce qu’on rangeExemple en blocsOù trouver le bloc
Nombre entier : quantité, compteur, nombre d’objets
Math : bloc nombre
Nombre décimal : température, longueur, prix, vitesse
Math : bloc nombre, avec un point
Texte : nom, message, étiquette
Texte : bloc avec guillemets « »
Les nombres décimaux s’écrivent avec un point : 4.5, et pas 4,5.

Créer et utiliser une variable avec les blocs, pas à pas

Objectif : construire ce petit programme, puis l’exécuter.
  1. Ouvrir Vittascience et choisir l’affichage Blocs. Ouvrir Vittascience
  2. Cliquer sur la catégorie Variables, puis sur « Créer une variable… ». Taper le nom score (sans espace ni accent) et valider.
  3. Glisser le bloc affecter à score la valeur dans la zone de travail. Si besoin, choisir score dans la petite liste ▾.
  4. Dans Math, prendre le bloc nombre, l’accrocher dans le trou à droite et taper 10.
  5. Ajouter un 2e bloc affecter à score la valeur sous le premier (ils doivent s’emboîter). Y mettre le bloc d’opération +, puis à gauche le bloc variable score et à droite le nombre 5.
  6. Dans Affichage, ajouter afficher en dessous, et y mettre le bloc variable score.
  7. Cliquer sur ▶ Exécuter : la console affiche 15.
Les 3 erreurs les plus fréquentes :
  • Un bloc posé à côté au lieu d’être emboîté : il n’est pas exécuté.
  • La mauvaise variable choisie dans la liste ▾ (par exemple x au lieu de y).
  • Un bloc texte « score » au lieu du bloc variable score : on affiche le mot, pas la valeur.
