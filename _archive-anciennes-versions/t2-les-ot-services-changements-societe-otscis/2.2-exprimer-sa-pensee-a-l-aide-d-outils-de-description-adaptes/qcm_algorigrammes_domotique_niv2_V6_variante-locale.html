📚 Rappel de cours : algorithmes & algorigrammes

Un algorithme est une suite ordonnée d’instructions permettant de résoudre un problème. C’est une recette très précise que l’on peut exécuter étape par étape.

Un algorigramme (ou organigramme) est une représentation graphique de l’algorithme : on utilise des symboles normalisés (ovale, rectangle, parallélogramme, losange, rectangle barré, flèches…) pour représenter les étapes.

Forme géométrique Rôle Symbole
Ellipse / Ovale (Début / Fin) Marque le début ou la fin de l’algorithme.
Rectangle (Action) Représente un traitement ou une action (calcul, affectation, commande…).
Parallélogramme (Entrée / Sortie) Représente la lecture ou l’affichage d’une donnée (entrée/sortie).
Losange (Test / Condition) Pose une question (Vrai/Faux – Oui/Non) pour choisir un chemin.
Rectangle barré (Sous-programme) Représente un sous-programme (procédure ou fonction) appelé depuis l’algorithme principal.
Sous-programme : bloc d’instructions réutilisable que l’on appelle depuis le programme principal. Il permet de simplifier l’algorigramme, de réduire les répétitions et de faciliter les tests.
Commentaire : texte non exécuté, ajouté pour expliquer le rôle d’une partie de l’algorithme. En pseudo-code, on peut par exemple commencer par //.
Flèches : elles indiquent le sens de circulation de l’algorithme (ordre d’exécution) entre les symboles. Une flèche mal orientée peut changer complètement le fonctionnement.
Les symboles d’algorigramme sont également disponibles en images SVG dans le dossier Images de cette séquence (par exemple Code_graphique_Action.drawio.svg). Une fois le projet envoyé sur GitHub, ces images seront visibles en ligne dans la page HTML.

En technologie, tu dois savoir :

  • Lire un algorithme textuel (écrit sous forme de phrases ou de pseudo-code).
  • Lire un algorigramme et expliquer ce qu’il fait.
  • Prévoir la valeur finale d’une variable après exécution.
  • Construire ou compléter un algorigramme simple (actions, conditions, boucles, sous-programmes).
  • Identifier les commentaires et suivre correctement les flèches.

Fonction logique ET

L’utilisation de la fonction logique ET est essentielle pour présenter correctement une solution.

  • A, B : variables d’entrée.
  • S : variable de sortie.

🧠 1. Forme algébrique booléenne

S = A . B

  • S est vrai (1) uniquement si A et B sont tous les deux vrais (1).

🔤 2. Forme textuelle explicite

S est vrai si A est vrai ET B est vrai.

🔘 3. Forme conditionnelle

Si A = 1 ET B = 1 alors S = 1, sinon S = 0.

Fonction logique OU

La fonction logique OU permet d’allumer la sortie si au moins une des entrées est active.

🧠 1. Forme algébrique booléenne

S = A + B

🔤 2. Forme textuelle explicite

S est vrai si A est vrai OU B est vrai (ou les deux).

🔘 3. Forme conditionnelle

Si A = 1 OU B = 1 alors S = 1, sinon S = 0.

🔄 4. Table de vérité

Table de vérité OU

L’ampoule S s’allume si A est fermé OU si B est fermé (ou les deux). Cliquez sur les interrupteurs (ou Espace/Entrée).

S = 0 (éteinte)

Logique : S = A OU B. Interrupteurs en parallèle. Fermer A ou B pour allumer S.

Algorithme et gestion des sous-problèmes

L’utilisation de sous-programmes est idéale pour une meilleure lisibilité, pour alléger l’algorithme lorsqu’il y a des actions répétitives, pour faciliter le travail en collaboration et pour simplifier la recherche d’erreur (tests séparés de chaque sous-programme).
