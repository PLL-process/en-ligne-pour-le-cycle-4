# Banque DNB « algorigrammes » — version 1, archivée le 08/08/2026

Ces deux fichiers viennent d'une organisation antérieure du dépôt. Ils étaient jusqu'ici dans le
dossier actif `3e_C6.2`.

| Fichier | Contenu |
|---|---|
| `sequence_algorigrammes_dnb.html` | 30 exercices interactifs, 13 SVG inline, 32 aides rédigées |
| `qcm_algorigrammes_dnb.html` | 17 questions |

## Pourquoi ils sont ici

Ils sont **remplacés**, pas supprimés, par
`theme-2-…/C6-…/3e/3e_C6.2/entrainement_dnb_algorigrammes.html`, qui reprend les mêmes notions au
gabarit maison. La nouvelle page apporte trois choses que celle-ci n'avait pas :

- la **réfutation de chaque réponse fausse** — 90 réfutations rédigées. C'est la raison
  principale : au brevet les distracteurs sont conçus pour être plausibles, et savoir *pourquoi*
  une réponse est fausse vaut mieux que savoir laquelle est juste ;
- la **sauvegarde locale** des réponses, et un **mode essentiel** pour alléger la page ;
- **deux niveaux d'aide** par exercice, avec la mention explicite que les utiliser n'est pas
  tricher.

Laisser les deux versions côte à côte dans le dossier actif aurait fait travailler une partie des
élèves sur celle qui n'a pas les réfutations, sans qu'aucune page ne le leur dise.

## Ce qui a été fait au moment du déplacement

Les deux seuls liens du dépôt qui pointaient vers ces fichiers — dans les séquences 3e_C6.1 et
3e_C6.2 — ont été redirigés vers le nouvel entraînement. `index.html` et l'audit ont été
régénérés.

Le contenu de ces deux fichiers n'a **pas** été modifié : ils sont ici tels qu'ils étaient.
