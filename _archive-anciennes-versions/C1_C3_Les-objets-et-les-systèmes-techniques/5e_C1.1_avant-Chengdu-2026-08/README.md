# 5e_C1.1 — état antérieur au lot « Chengdu » (archivé le 8 août 2026)

Ces sept fichiers occupaient le dossier `5e/5e_C1.1/` avant la livraison du lot
**Chengdu : le collège qui mesure son air**. Ils sont archivés, pas supprimés.

## Ce qui a été repris avant d'archiver (règle n°12)

Le plan du lot a été **réécrit après lecture intégrale** de `sequence.html` (63 ko) — la première
version avait été écrite sans l'ouvrir, ce qui n'est pas une lecture (règle n°46). Ont été repris :

- le **triptyque collecter / trier / analyser**, qui structure encore la séance 2 ;
- les **modes opératoires tableur**, conservés et complétés : l'ancienne séquence donnait Excel en
  français, le nouveau lot donne **Excel et LibreOffice Calc**, avec la remarque que les formules
  sont les mêmes et que seuls les menus changent ;
- les **questions métacognitives** de fin de séquence, reprises presque telles quelles dans le
  bilan (`meta1`, `meta2`, `meta3`) ;
- le principe de l'**autoévaluation par code** ;
- l'idée d'une **galerie de capteurs**, transformée en comparaison de trois principes de mesure
  (activité 1), ce qui la rattache à un code du référentiel — `5e_C1.2` — qu'elle ne servait pas.

## Ce qui n'a pas pu être repris

- **trois images cassées** : `{{analysis_icon}}`, `{{sensor_icon}}`, `{{sort_icon}}` — des variables
  de gabarit jamais remplacées, laissées dans des attributs `src` ;
- un appel à **Google Fonts**, incompatible avec le fonctionnement hors ligne (règle n°40) ;
- un en-tête annonçant « classe de **4e** » sur un fichier rangé en 5e ;
- **12 images en base64** de provenance inconnue, donc de licence inconnue (règle n°1) ;
- une dérive vers **Arduino**, qui relève du C4 et non du C1.
