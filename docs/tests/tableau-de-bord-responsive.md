# Contrôle responsive du tableau de bord

- grille 3 colonnes avec `minmax(0,1fr)` ;
- passage à 2 colonnes sous 980 px ;
- passage à 1 colonne sous 680 px ;
- cartes autorisées à rétrécir avec `min-width:0` ;
- noms de ressources autorisés à revenir à la ligne ;
- code `3e_C1.5` toujours présent après régénération.

Ce correctif répond au débordement observé sur la capture fournie par Pascal.
